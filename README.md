# Сервис рациональных решений

Учебный проект (дипломная работа). Обычный сайт на HTML, CSS и JavaScript — без фреймворков.

## Структура

- `index.html` — главная
- `login.html` — вход
- `register.html` — регистрация (с чекбоксами 152-ФЗ и пользовательским соглашением)
- `privacy.html` — политика конфиденциальности
- `terms.html` — пользовательское соглашение
- `css/styles.css` — стили (синий/белый, шрифт Inter)
- `js/main.js` — общий скрипт

## Как открыть

1. Дважды кликнуть по `index.html` — откроется в браузере.
2. Или запустить локальный сервер (чтобы не было ограничений с file://):
   - **Python:** `python -m http.server 8000` → в браузере открыть http://localhost:8000
   - **Node:** `npx serve` в папке проекта

Бэкенд (авторизация, сохранение решений) можно добавить позже (например Node + Express или Python + Flask/FastAPI).
