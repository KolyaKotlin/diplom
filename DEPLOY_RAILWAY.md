# Развёртывание на Railway

Бесплатный деплой Flask-приложения на Railway (доступно из РФ без VPN).

---

## Шаг 1. Регистрация

1. Зайди на [railway.app](https://railway.app)
2. Нажми **Login** → **Login with GitHub**
3. Авторизуйся через свой GitHub-аккаунт

---

## Шаг 2. Создание проекта

1. На главной странице Railway нажми **New Project**
2. Выбери **Deploy from GitHub repo**
3. Выбери репозиторий **KolyaKotlin/diplom**
4. Railway автоматически определит Python и начнёт сборку

---

## Шаг 3. Переменные окружения

1. Открой созданный сервис (карточка с твоим приложением)
2. Перейди во вкладку **Variables**
3. Добавь переменные:

| Переменная   | Значение                          |
|--------------|-----------------------------------|
| `SECRET_KEY` | Любая случайная строка            |
| `ADMIN_EMAILS` | Твой email для админки          |

---

## Шаг 4. Публичный домен

1. Во вкладке **Settings** найди раздел **Networking**
2. Нажми **Generate Domain**
3. Railway выдаст ссылку вида: `diplom-production-xxxx.up.railway.app`

---

## Шаг 5. Деплой

Railway автоматически соберёт и запустит приложение. Дождись статуса **Success** (обычно 2–4 минуты).

---

## Шаг 6. Проверка

Открой сгенерированный домен в браузере — должен открыться твой сервис.

---

## Важно

- **Бесплатный тариф:** 500 часов в месяц. Для диплома обычно хватает.
- **База данных:** SQLite сохраняется в контейнере. При перезапуске/пересборке данные могут сброситься. Для демо диплома это допустимо.
- **Автодеплой:** При каждом `git push` в `main` Railway пересоберёт и задеплоит приложение.

---

## Если что-то пошло не так

Во вкладке **Deployments** нажми на последний деплой и посмотри **Logs** — там будет текст ошибки.
